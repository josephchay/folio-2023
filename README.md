## Development

1. Clone the repository:
    
    ```bash
    git clone https://github.com/josephchay/folio-2023
    ```
   
2. Navigate to the project directory:
    
    ```bash
    cd folio-2023
    ```
   
3. Install the dependencies:
    
    ```bash
    npm install
    ```
   
4. Run the development server:
    
    ```bash
    npm run dev
    ```

## Deployment

1. Build the project:
    
    ```bash
    npm run build
    ```
